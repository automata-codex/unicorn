# Pin policy:
#   marker-pdf is pinned exactly and the pin is load-bearing. Extraction
#   varies across marker versions, and that variance changes which fixup
#   patches in <system>/fixups.json still apply. Bumping it is a deliberate
#   decision that should be re-verified against ingestion/<system>/hashes/,
#   not a routine dependency refresh.
#
#   voyageai is pinned exactly because the embedding call is the one step
#   whose output silently changes meaning rather than failing loudly.
#
#   psycopg and tiktoken float above a floor. Neither affects what lands in
#   the index: psycopg is a driver over plain SQL, and tiktoken only counts
#   tokens for the ~400-token chunking heuristic, which has no hard boundary.
